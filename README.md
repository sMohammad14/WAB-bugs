با سلام
این صفحه قرار هست به طور منظم به باگ ها، ضعف ها و نکات امنیتی سامانه PAM شرکت Wallix، مشخصا محصول Wallix Pastion بپردازه.
با چند نفر از علاقه مندان این حوزه داریم بررسی هایی میکنیم با هدف آگاهی بیشتر در مورد این محصول و شناخت موارد امنیتی، که در نهایت منجر به پیشگری و امن سازی این سامانه توسط استفاده کنندگان بشه.

مواردی که بهشون دست یافتیم و مشغول کار بر روی آنها هستیم:

- این سامانه در برابر ضعف خای CSP اصلا مقاوم نیست.
- نقض قوانین دیتابیس از طریق API های رسمی سامانه
- موارد Pivoting و Management Plane Breach
