با سلام
این صفحه قرار هست به طور منظم به باگ ها، ضعف ها و نکات امنیتی سامانه PAM شرکت Wallix، مشخصا محصول Wallix Pastion بپردازه.
با چند نفر از علاقه مندان این حوزه داریم بررسی هایی میکنیم با هدف آگاهی بیشتر در مورد این محصول و شناخت موارد امنیتی، که در نهایت منجر به پیشگری و امن سازی این سامانه توسط استفاده کنندگان بشه.

مواردی که بهشون دست یافتیم و مشغول کار بر روی آنها هستیم:

- این سامانه در برابر ضعف های CSP اصلا مقاوم نیست و آسیب پذیری های XSS داره.
- نقض قوانین دیتابیس از طریق API های رسمی سامانه امکان پذیر هست
- موارد Pivoting و Management Plane Breach در این نرم افزار شناسایی شده
- رابط کاربر دیفالت سامانه که به عنوان رابط کاربری جدید شناخته میشه،در برخی صفحات در واقع همان رابط کاربری قدیمی هست، به این صورت که UI قدیمی در یک iframe گنجانده شده و با هدر و منو های کناری UI جدید به کاربر نشون داده میشه. این موضوع به خودی خود، ریسکی ایجاد نمیکنه ولی، آسیب پذیری های UI قدیمی به UI جدید هم منتقل شده!
